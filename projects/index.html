Overview

Why loss function choice matters for ultrasound segmentation

Accurate segmentation of lesions in breast ultrasound images is essential for clinical diagnosis, treatment planning, and quantitative biomedical analysis — but manual delineation is slow, observer-dependent, and highly sensitive to the speckle noise, low tissue contrast, and poorly defined boundaries that are inherent to ultrasound imaging.

This project builds an automated breast lesion segmentation system on the U-Net architecture, trained and evaluated on the public Breast Ultrasound Images (BUSI) dataset. Rather than tuning a single model, the core experiment holds architecture, data, and training schedule fixed and varies only the loss function — Binary Cross-Entropy, Mean Squared Error, Dice Loss, combined Dice–BCE, and Focal Loss — to isolate exactly how much the training objective matters for class-imbalanced medical segmentation.

Every model is evaluated on an identical held-out test set using the Dice coefficient and Intersection over Union (IoU). Segmentation-aware losses consistently beat pixel-wise regression objectives, with Focal Loss coming out on top at a Dice score of 0.783 and IoU of 0.644, versus MSE's 0.661 / 0.498.

Method

Dataset, preprocessing & the U-Net pipeline

Dataset

The BUSI dataset contains 780 grayscale ultrasound images (benign, malignant, and normal cases) paired with binary ground-truth masks. All 780 image–mask pairs are used, split 80 / 10 / 10 into train, validation, and test sets via stratified random sampling with a fixed seed for reproducibility.

Preprocessing & augmentation

Images are resized to 256×256 and normalized to zero mean / unit variance. Only the training split is augmented, via Albumentations:

  • Horizontal (p=0.5) and vertical (p=0.3) flips
  • Random rotation within ±30°
  • Affine transforms — scale 0.85–1.15×, translate ±10%, rotate ±20°
  • Elastic deformation and grid distortion (p=0.3 each)
  • Random brightness / contrast perturbation (±20%)
  • Gaussian blur and Gaussian noise injection (p=0.2 each)

Validation and test images are only resized and normalized — no stochastic augmentation.

U-Net architecture

A standard U-Net with batch normalization: four encoder blocks (each two 3×3 convolutions + BatchNorm + ReLU) doubling channels 64→128→256→512, connected by 2×2 max-pooling; a 1024-channel bottleneck; and a mirrored decoder using transposed-convolution upsampling with skip connections back to each encoder stage. The output is a single-channel sigmoid map. ≈31.0M trainable parameters in total.

Training setup

Adam optimizer (lr = 1e-4), 50 epochs, batch size 16, on an NVIDIA RTX 4080. A ReduceLROnPlateau scheduler (patience 5, factor 0.5, min_lr 1e-6) decays the learning rate on validation-loss plateaus; the checkpoint with the best validation loss is kept for final test-set evaluation.

Loss Functions

Five loss functions, one identical U-Net

Each loss is trained under the exact same architecture, data splits, and schedule so that any performance gap comes from the objective alone.

Binary Cross-Entropy
L = −[y·log(p) + (1−y)·log(1−p)]

Penalizes every pixel independently. Sensitive to class imbalance since background vastly outnumbers lesion pixels.

Mean Squared Error
L = (p − y)²

Included as a regression baseline. Not naturally suited to binary segmentation — the weakest performer here.

Dice Loss
L = 1 − (2|P∩T|+ε) / (|P|+|T|+ε)

Directly maximizes mask overlap. Inherently robust to class imbalance by operating on whole regions.

Dice + BCE
L = LDice + LBCE

Hybrid objective that stabilizes gradients while keeping Dice's overlap-maximizing property.

Focal Loss Best
L = α(1−pt)γ·BCE(p,y)

α=0.8, γ=2 — down-weights easy background pixels and concentrates learning on hard boundary pixels.

Discussion

Key findings

01

Losses that encode spatial overlap (Dice, DiceBCE, Focal) consistently and substantially outperform losses that treat pixels independently (BCE, MSE).

02

MSE is the weakest objective for binary segmentation — minimizing squared error doesn't reward spatial coherence, so predictions stay diffuse and low-confidence.

03

Focal Loss edges out the rest by suppressing gradient from easy, well-classified background and concentrating learning on ambiguous boundary pixels — the main source of error in low-contrast ultrasound.

04

Dice and DiceBCE land almost identically, suggesting the extra BCE term adds little here, though it may help stability on more heterogeneous datasets.

05

No model introduces systematic false positives on normal (lesion-free) tissue — every loss function correctly predicts an all-black mask on those cases.

06

Limitations: a plain U-Net without attention or residual connections, benign/malignant/normal treated uniformly, and a fixed 50-epoch budget — all natural directions for follow-up work (attention U-Net, transformer decoders, multi-class analysis, loss-specialized ensembles).
